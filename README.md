## Issues I ran into and how I solved them
**Claude Code and Codex not visible in Marketplace**

The Claude Code and Codex extensions did not initially appear in the marketplace. To resolve this, I searched for installation guides on Google and YouTube. I found that opening the Extensions panel manually using `Cmd + Shift + X` allowed me to access the search bar. From there, I was able to locate and install the Claude Code extension successfully.

**Subscription Limitation & Workaround**

Claude Code requires a subscription
After testing both Claude and Codex extensions, I confirmed that they function correctly. However, Claude requires usage credits or a paid subscription to operate.

As a workaround, I configured access to a free Claude Code alternative hosted on GitHub (Alishahryar1/free-claude-code) and integrated it via the terminal, following guidance from this tutorial: https://www.youtube.com/watch?v=U6gg_bi1I70

Since OpenRouter was not functioning in my setup, I used NVIDIA as the provider instead.
